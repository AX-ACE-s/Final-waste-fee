# Full-waste-fee

# 우리동네 대형폐기물 AI 수거비용 안내

▶ **시연 영상:** https://youtu.be/RQVQO4rz0n8

## 서비스 소개

대형폐기물 수수료는 지자체마다 품목 이름과 규격 기준, 금액이 다릅니다. 같은 소파라도 어느 동네는 '1인용당' 금액을 매기고 어느 동네는 '3인 이상'처럼 구간으로 나누기 때문에, 주민이 내 물건이 어느 품목·규격에 해당하는지 스스로 판단하기 어렵습니다. 신청 메뉴의 위치도 구청 누리집마다 달라 수수료를 확인하고 신고하기까지 여러 곳을 찾아다녀야 합니다.

우리동네 대형폐기물 AI 수거비용 안내는 이 과정을 한곳에서 안내합니다. 사진 한 장이나 물건 이름으로 품목을 찾고, 우리 동네 수수료표에 필요한 규격만 답하면 공공데이터 기준 예상 수수료와 근거를 보여 주며, 내놓기 전에 확인할 것과 신청 페이지까지 연결합니다.

## 주요 기능

| 번호 | 기능 | 설명 |
|---|---|---|
| 01 | 사진 기반 품목 인식 | 사진을 올리면 AI가 우리 지역 수수료표에 있는 품목 중에서 후보와 판단 근거를 보여 줍니다. 가전이면 무상방문수거 안내를 함께 띄웁니다. |
| 02 | 지역 기준 규격 질문·실측 보정 | 지역 수수료표에서 금액을 가르는 규격만 묻고, 실측값으로 규격을 판정·보정합니다. '3인용 소파 2개'처럼 설명을 쓰면 인용·개수를 미리 채웁니다. |
| 03 | 수수료 산정·근거 안내 | 공공데이터 기준 예상 수수료와 기준일·출처, 다른 규격과의 비교, 조례 원문 링크를 보여 주고 여러 품목의 합계를 냅니다. |
| 04 | 배출 전 체크리스트·신청 연결 | 품목과 주거 형태에 맞춰 신고 전·물건 준비·내놓기 단계별 확인 항목을 보여 주고 구청 신청 페이지로 연결합니다. (서울 25개 자치구) |

## 이용 흐름

화면은 품목 확인 → 규격 확인 → 수수료·배출 안내 세 단계로 이어지며, 위쪽 단계 막대로 지금 위치를 보여 줍니다.

첫 화면에서 배출 지역을 시·도/시·군·구로 고르거나 주소로 찾은 뒤, 사진을 올리거나 이름으로 품목을 찾습니다. 품목 확인 화면에서 AI 후보와 근거를 보고 품목을 확정하면, 규격 확인 화면에서 그 지역 수수료표에 필요한 질문에만 답합니다. 마지막 화면에서 예상 수수료와 산정 근거를 확인하고 목록에 담아 합계를 볼 수 있으며, 배출 전 체크리스트(별도 페이지)와 신청 페이지로 이동합니다.

## 실행하기

Python 3.10 이상이 필요합니다.

```bash
pip install -r requirements.txt
cp .env.example .env      # 인증키는 선택 사항
python app.py
```

브라우저에서 `http://127.0.0.1:5000`을 엽니다. 인증키가 없어도 동작합니다. AI 키가 없으면 사진 인식은 연습용 가짜 응답으로, 주소 키가 없으면 지역 목록 검색으로 대신합니다.

## 사용 데이터

- 공공데이터포털 「전국대형폐기물수거수수료정보표준데이터」: 지역·품목·규격·수수료
- 행정안전부 도로명주소 검색 API: 주소 → 관할 지자체
- 법제처 국가법령정보 공동활용: 지자체 폐기물 관리 조례 원문 링크
- e순환거버넌스 폐가전 무상방문수거 이용 안내

```
├── requirements.txt
└── README.md
```
